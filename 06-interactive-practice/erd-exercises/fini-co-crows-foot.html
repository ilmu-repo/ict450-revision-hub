  • Record customers, staff, orders, packages and Malay confectionery.
  • Each order is placed by one customer and requests exactly one package.
  • An order must be placed at least three days before its event date. Check this when the order is placed; the model stores the event date, not a separate order-placement date.
  • Each package contains several confectionery items; the examples reuse the same confectionery across packages.
  • The question records staff but gives no rule connecting staff to an order. Do not invent that relationship.
Modelling note: ORDER needs a key, while PACKAGE and CONFECTIONERY need identifiers so the M:N relationship can be resolved. These identifiers are necessary design additions; StaffID is not placed in ORDER because the source never states that staff manage orders.
