Question context and notation used
  • Customers place orders for events; each order requests exactly one package.
  • An order must be placed at least three days before its event date. This is a validation rule, not another ERD relationship.
  • Every package contains one or more confectioneries, and a confectionery may appear in many packages.
  • Order details are the event date, event time and event location.
  • The question records staff details but gives no Staff-Order business rule. This practice does not invent one.
ICT450 convention: rectangles are entities, diamonds are relationships, ovals are attributes, and underlined ovals are key attributes. The relationship already represents the link, so separate foreign-key ovals are not used.
